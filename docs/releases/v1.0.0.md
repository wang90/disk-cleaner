# DiskCleaner 1.0.0

**首个正式版** 🎉  /  **First stable release**

A native macOS storage cleaner with a GUI: it shows you where your disk space actually went
and quietly keeps at least **10 GB** free.

---

## Download

按芯片选择对应安装包 / Choose the build for your Mac:

| 你的 Mac / Your Mac | 下载 / File |
|---|---|
| **Apple 芯片**（M1 / M2 / M3 / M4 …） | `DiskCleaner-v1.0.0-macos-arm64.zip` |
| **Intel 芯片** | `DiskCleaner-v1.0.0-macos-x86_64.zip` |

`uname -m` 在 Apple 芯片上输出 `arm64`，在 Intel 上输出 `x86_64`
（或点  → 关于本机 看芯片型号）。

`SHA256SUMS.txt` 是上面两个包的校验和，验证：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

解压后把 `DiskCleaner.app` 拖进 **/Applications**。

> **首次打开**：发布包是 ad-hoc 签名（未公证），系统会提示无法验证开发者。
> 请 **右键 → 打开**，再点一次「打开」；或执行
> `xattr -dr com.apple.quarantine /Applications/DiskCleaner.app`

> 界面目前为简体中文，英文版在路线图中。

## 相比 beta 版新增

- **应用数据管理**：点应用列表每行的 ⚙︎，可以查看该应用在 `~/Library` 下的数据，分为
  - **缓存 / 日志** —— 安全，默认勾选，应用会自动重建；
  - **用户数据 / 未知** —— 聊天记录、数据库、登录状态。默认**锁住**，需要手动打开
    「我了解风险」并在删除前二次确认；自动清理**永远不会**碰这些内容。

  分类是**按文件夹名字推断的**，认不出来的一律当「未知」锁住。
  删除聊天记录不可恢复，请先备份。
- **清理时的 loading**：转圈浮层 + `n / 总数` 计数 + 进度条 + 当前处理的路径。
- **菜单栏小图标**：图标旁显示可用空间，低于目标变 ⚠️，点击弹出磁盘/内存面板与快捷操作。
- **独立的「关于」窗口**（菜单 **磁盘清理 → 关于 磁盘清理**）。
- 设置里可选 **主题**（跟随系统 / 浅色 / 深色）、后台自动清理、文件位置。

## 其它能力

- 自动保持至少 10GB 可用：只在需要时清理，达到目标立即停止。
- macOS「储存空间」风格的分类条；鼠标划入色块看精确大小，`123` 按钮把数字标在条上。
- 每个应用占用（本体 + 用户数据）、每个硬盘/卷列表；磁盘十进制、内存二进制，与系统完全一致。
- 三级清理、白名单机制、受保护路径、硬超时兜底、拒绝 root 运行、完整日志位于
  `~/Library/Logs/diskautoclean.log`。
- 零依赖：纯 SwiftUI + 一个 shell 脚本，不联网、不上传任何数据。

## 安装包说明

从 1.0.0 起，每个芯片一个独立安装包（而不是之前的通用二进制）：

- 体积更小（arm64 约 568 KB / x86_64 约 600 KB，通用版约 1.0 MB）
- 两个包内的 `Info.plist`、内嵌脚本完全一致，只是可执行文件的架构不同
- 想自己构建通用版：`ARCHS="arm64 x86_64" ./build.command`
