# DiskCleaner v1.0.0

First public release 🎉

A native macOS storage cleaner with a GUI: it shows you where your disk space actually went
and quietly keeps at least **10 GB** free.

---

## Download

| File | Notes |
|---|---|
| `DiskCleaner-v1.0.0-macos-universal.zip` | Universal binary — Apple Silicon **and** Intel, macOS 14+ |
| `DiskCleaner-v1.0.0-macos-universal.zip.sha256` | SHA-256 checksum |

Unzip, then drag `DiskCleaner.app` into **/Applications**.

> **First launch:** the build is ad-hoc signed (not notarized), so macOS will say it cannot
> verify the app. **Right-click → Open**, then click *Open* again — or run:
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/DiskCleaner.app
> ```

> The app UI is currently in **Simplified Chinese**. English localization is the top roadmap
> item — PRs are welcome.

## Highlights

**Know where your space went**
- macOS *Storage*-style colour bar: Applications, Documents & Desktop, Downloads, Photos,
  Music, Movies, Mail & Messages, Developer caches, App data, System & app caches,
  System data & other, Free.
- **Hover any segment** for its exact size and share; toggle the **123** button to print
  the numbers right on the bar.
- Per-app usage: bundle size **plus** its user data (`~/Library/Containers`,
  `~/Library/Caches`, `~/Library/Application Support`), sorted by size.
- Per-volume list: the boot container plus any external disks or mounted images.
- Numbers match macOS exactly — decimal units for storage (`245.1 GB`), binary for memory
  (`16 GB`).

**Never run out of space**
- Background agent checks hourly; cleans only when free space is below your target and
  **stops the moment the target is met**. It never over-cleans.
- Three tiers: safe caches → developer caches → user data (opt-in only).
- Huge logs are **truncated, not deleted**, so the process writing them keeps working.

**Safe by design**
- Whitelist-only targets, all inside your home directory.
- `~/Documents`, `~/Desktop`, `~/Pictures`, `~/.ssh`, `~/Library/Keychains`, `/System`,
  `/Library`, `/usr` … are refused outright.
- Age-based deletion, NUL-safe file iteration, hard per-path `du` timeout,
  refuses to run as root, single-instance lock, full audit log.

**No dependencies**
- Pure SwiftUI + a shell script. Nothing to install, no network access, no telemetry.

## 中文说明

首个公开版本 🎉

一个原生 macOS 储存空间工具：看清空间去哪了，并自动保持至少 **10 GB** 可用。

### 下载

下载 `DiskCleaner-v1.0.0-macos-universal.zip`（通用二进制，Apple Silicon 与 Intel 均可），
解压后把 `DiskCleaner.app` 拖进「应用程序」。

> 首次打开：发布包是 ad-hoc 签名（未公证），系统会提示无法验证开发者。
> 请 **右键 → 打开**，再点一次「打开」；或执行
> `xattr -dr com.apple.quarantine /Applications/DiskCleaner.app`

> 界面目前为简体中文，英文版在路线图中。

### 主要功能

- **储存空间分类**（macOS 风格彩色条）：应用程序、文稿与桌面、下载、照片、音乐、影片、
  邮件与信息、开发者缓存、应用数据、系统与应用缓存、系统数据与其它、可用。
  **鼠标划入色块**看精确大小；点 **123** 按钮把数字标在色块上。
- **每个应用占用**：App 本体 + 用户数据，按大小排序，可点击定位。
- **每个硬盘/卷**：启动容器 + 外接硬盘 / 磁盘映像。
- **自动保底 10GB**：每小时检查，低于目标才清理，达标立即停止。
- **三级清理**：安全缓存 → 开发缓存 → 用户数据（默认只报告）。
- **安全**：白名单 + 受保护路径 + 按时间删除 + 硬超时 + 完整日志。
- **零依赖**：只用 macOS 自带工具，不联网、不上传任何数据。
