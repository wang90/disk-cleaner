## Download

| 你的 Mac / Your Mac | 下载 / File |
|---|---|
| **Apple 芯片**（M1 / M2 / M3 / M4 …） | `DiskCleaner-v1.1.0-macos-arm64.zip` |
| **Intel 芯片** | `DiskCleaner-v1.1.0-macos-x86_64.zip` |

`uname -m` 输出 `arm64` 是 Apple 芯片，`x86_64` 是 Intel。
`SHA256SUMS.txt` 是两个包的校验和：`shasum -a 256 -c SHA256SUMS.txt`

解压后把 `DiskCleaner.app` 拖进 **/Applications**。

> **首次打开**：ad-hoc 签名（未公证），需 **右键 → 打开**，或
> `xattr -dr com.apple.quarantine /Applications/DiskCleaner.app`

## 本次新增

### 检查更新

- **自动**：启动时检查一次，之后每 12 小时一次（默认开启，可关闭）
- **手动**：设置 → 更新 →「检查更新」，同处显示**当前版本**
- 有新版本时，主界面表头与「关于」窗口会出现绿色 **有新版本 x.y.z** 胶囊，点击前往下载页
- 版本比较遵循语义化版本：`1.0.0` 比 `1.0.0-beta.4` 新，`1.0.10` 比 `1.0.9` 新

**关于隐私**：这是整个应用**唯一**的联网请求 —— 只向 GitHub 公开 API 读一次最新版本号，
不发送任何关于你 Mac、磁盘、文件或使用情况的信息，也没有任何统计埋点。
关掉「自动检查更新」后，应用完全不碰网络。

### 分享

主界面表头与「关于」窗口新增**分享**按钮，调用 macOS 原生分享面板，
分享本项目的 GitHub 链接（邮件 / 信息 / AirDrop / 拷贝链接…）。
